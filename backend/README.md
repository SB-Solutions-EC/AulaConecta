# backend — API de AulaConecta

API en **NestJS + TypeScript** con **PostgreSQL** (Prisma). Expone la autenticación por rol, la gestión académica, la matrícula, la planificación, las calificaciones, los reportes y los avisos por WhatsApp.

| Cuándo | Qué se construye |
|---|---|
| Sprint 3 (27/10) | Esqueleto con `/health`, configuración por variables de entorno y Swagger |
| Sprint 3 (28/10) | Prisma, esquema inicial y migraciones |
| Sprint 4 en adelante | Módulos según el Product Backlog |
