# frontend — PWA de AulaConecta

Aplicación web instalable (**PWA**) en **React + Vite + TypeScript** con Tailwind. Funciona en computadora y celular, y permite registrar notas y asistencia sin conexión (IndexedDB + service worker) para sincronizar después.

| Cuándo | Qué se construye |
|---|---|
| Sprint 3 (27/10) | Esqueleto con los colores del colegio, conectado a `/health` |
| Sprint 3 (28/10) | Rutas por rol y diseño adaptable tomado del prototipo |
| Sprint 9 | Trabajo sin conexión y sincronización |
